# ۱۳ — واژه‌نامه

> اصطلاحات فنی این پروژه، به ترتیب الفبای انگلیسی.

| اصطلاح | معنی/توضیح |
|---|---|
| **AIO** | All-In-One؛ بستهٔ ادغام‌شده (مثلاً HENloader که Lapse و Poops را با هم دارد) |
| **AIO Fix** | اصلاحات اضافی برای مشکلات صفحهٔ سیاه/خرابی سیو در Lapse |
| **AIO (Kernel)** | Asynchronous I/O؛ زیرسیستم I/O ناهمگام که Lapse در آن آسیب‌پذیری دارد |
| **AllPermission** | مجوز کامل در مدل امنیتی جاوا |
| **BD-J** | Blu-ray Disc Java؛ محیط اجرای برنامه‌های جاوا روی دیسک بلوری |
| **BD-JB** | Blu-ray Disc Java Sandbox Escape؛ اکسپلویت فرار از سندباکس جاوا |
| **BD-LIVE** | قابلیت شبکه‌ای بلوری؛ پخش‌کننده ممکن است اجازهٔ اتصال بخواهد |
| **BD-R** | دیسک بلوری قابل رایت یک‌بار |
| **BD-RE** | دیسک بلوری قابل بازنویسی |
| **BDXL** | استاندارد بلوری ظرفیت بالا؛ برای BD-JB PS4 پشتیبانی نمی‌شود |
| **BDMV** | ساختار فایل‌های دیسک بلوری |
| **BDJO** | فایل توصیف‌گر برنامهٔ BD-J (شامل `baseDirectory` و `applicationId`) |
| **BinLoader** | سرویس دریافت پیلود روی شبکه (پورت ۹۰۲۰ در لودرهای BD-JB؛ ۹۰۹۰ در GoldHEN) |
| **Celsius** | نام یک کرنل اکسپلویت/باگ (گزارش انجمنی برای ۱۳.۰۴؛ `ffs_mount`) |
| **CVE** | Common Vulnerabilities and Exposures؛ شناسهٔ رسمی آسیب‌پذیری |
| **Double Free** | آزادسازی دوبارهٔ یک قطعه حافظه؛ منجر به UAF/آسیب‌پذیری |
| **fdrop / fhold** |کاهش/افزایش شمارندهٔ ارجاع فایل در کرنل FreeBSD |
| **FTP** | پروتکل انتقال فایل؛ GoldHEN روی پورت ۲۱۲۱ |
| **GoldHEN** | HEN محبوب PS4 با قابلیت‌های اضافه |
| **HEN** | Homebrew Enabler؛ فعال‌کنندهٔ اجرای هوم‌برو |
| **HENloader LP** | بستهٔ AIO شامل Lapse + Poops + GoldHEN |
| **Ixc** | Inter-Xlet Communication؛ ارتباط بین Xletها |
| **JIT** | Just-In-Time؛ کامپایل در زمان اجرا؛ در PS4 JVM فعال است |
| **KASLR** | Kernel Address Space Layout Randomization؛ تصادفی‌سازی آدرس کرنل |
| **KEX** | Kernel Exploit؛ اکسپلویت کرنل |
| **Klog** | Kernel Log؛ GoldHEN روی پورت ۳۲۳۲ |
| **Lapse** | کرنل اکسپلویت double free در AIO؛ ۵.۰۰–۱۲.۰۲ |
| **libkernel_sys** | کتابخانهٔ سیستمی با دسترسی بیشتر؛ فرایند BD-J از آن استفاده می‌کند |
| **libkernel_web** | نسخهٔ محدود کتابخانه برای مرورگر |
| **NPXS20113** | شناسهٔ برنامهٔ پخش‌کنندهٔ بلوری PS4 |
| **Payload** | باینری/برنامهٔ اجراشده پس از کرنل اکسپلویت (GoldHEN/HEN) |
| **PKG** | بستهٔ نصب PS4 |
| **Poopsploit** | کرنل اکسپلویت double fdrop در `sys_netcontrol`؛ PS4 ≤13.00 |
| **PRISON0** | ساختار امنیتی کرنل برای محدودسازی فرایندها |
| **PUP** | بستهٔ به‌روزرسانی رسمی فریمور PS4 |
| **Relapse** | نام یک کرنل اکسپلویت/جیل‌بریک (PS4 13.02–13.04 و PS5)؛ گزارش انجمنی |
| **RTHDR** | Routing Header در IPv6؛ در Poopsploit برای spray استفاده می‌شود |
| **RWX** | حافظهٔ قابل خواندن/نوشتن/اجرا |
| **SecurityManager** | کلاس جاوا برای اعمال سیاست‌های امنیتی |
| **system_ex** | پارتیشن سیستمی محافظت‌شدهٔ PS4؛ شامل پخش‌کنندهٔ بلوری |
| **UAF** | Use-After-Free؛ استفاده از حافظهٔ آزادشده |
| **Ucred** | ساختار اعتبارسنجی کاربر در کرنل (UID/GID/caps) |
| **Unsafe** | کلاس جاوا برای دسترسی به حافظهٔ خام |
| **Xlet** | برنامهٔ جاوا روی دیسک بلوری |
| **XOM** | Execute-Only Memory؛ محدودیت اجرای حافظه در PS5 |
