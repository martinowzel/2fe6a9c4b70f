### نکته دربارهٔ ISOها

- ISOهای BD-JB معمولاً کوچک (حدود ۱۶ مگابایت) هستند و باید روی **BD-R/BD-RE** رایت شوند.
- بعضی نسخه‌ها پیلود داخلی دارند و بعضی `payload.bin` از USB می‌خوانند.
- قبل از رایت، README نسخه را بخوانید: برخی نسخه‌ها مخصوص فریمور خاصی هستند.

### ساخت ISO با `bdj-sdk` (خلاصه)

```bash
sudo apt-get install build-essential libbsd-dev git pkg-config \
    openjdk-8-jdk-headless openjdk-11-jdk-headless
git clone --recurse-submodules https://github.com/john-tornblom/bdj-sdk
ln -s /usr/lib/jvm/java-8-openjdk-amd64 bdj-sdk/host/jdk8
ln -s /usr/lib/jvm/java-11-openjdk-amd64 bdj-sdk/host/jdk11
make -C bdj-sdk/host/src/makefs_termux
make -C bdj-sdk/host/src/makefs_termux install DESTDIR=$PWD/bdj-sdk/host
make -C bdj-sdk/target
make -C bdj-sdk/samples/helloworld
```

خروجی نمونه: `bdj-sdk/samples/helloworld/helloworld.iso`.

## ۹. هشدار دربارهٔ منابع ناشناس

- ریپوهای تکراری/فورک‌شده می‌توانند حاوی پیلود مخرب باشند. تا حد امکان از ریپوی اصلی/سازنده استفاده کنید.
- فایل‌های `payload.bin`، ISO و JAR را قبل از اجرا با هش/آنتی‌ویروس بررسی کنید.
- لینک‌های کوتاه‌شده، فایل‌های پرسرور رایگان و «جیل‌بریک یک‌کلیکی» را جدی نگیرید.
- هیچ پروژهٔ معتبری از شما نمی‌خواهد PSN/رمز/اطلاعات شخصی بدهید.
