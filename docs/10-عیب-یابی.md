# ۱۰ — عیب‌یابی

> این سند مشکلات رایج مسیر BD-JB را جمع‌آوری می‌کند. اگر مشکل شما اینجا نبود، لاگ ابزار (پورت ۱۸۱۹۴) و README همان نسخه را بررسی کنید.

## ۲. مشکلات رایج با جزئیات

### ۲.۱ اکسپلویت شکست می‌خورد

- **ری‌استارت کامل** کنید (نه فقط بستن اپ).
- USB را قبل از دیسک وصل کنید.
- دیسک را دوباره وارد کنید و Blu-ray Player را باز کنید.
- اگر چند بار پشت‌سرهم شکست خورد، دیسک را دوباره رایت کنید (مخصوصاً BD-RE).
- برخی نسخه‌ها در اولین اجرا بعد از روشن شدن کنسول پایدارترند.

### ۲.۲ خطای `NW-31201-7`

طبق راهنمای ConsoleMods:

1. `Settings → System → Automatic Downloads`
   - `Allow Restart` را بردارید.
   - `System Software Update Files` را بردارید.
2. `Settings → Network → Set up Internet Connection` را با Easy setup دوباره تنظیم کنید.
3. `Settings → System → Enable HDCP` را فعال کنید.

### ۲.۳ دیسک خوانده نمی‌شود

- ISO را به‌صورت **data disc** رایت نکرده باشید؛ باید image باشد.
- دیسک باید **BD-R یا BD-RE** باشد؛ DVD/CD/BDXL کار نمی‌کند.
- سرعت رایت را کم کنید و `Verify` را فعال کنید.
- برای BD-RE، `permanent write` را غیرفعال کنید.
- لنز/درایو PS4 ممکن است کثیف باشد؛ با یک دیسک بلوری معمولی تست کنید.
- برخی دیسک‌های ارزان در PS4 خوانده نمی‌شوند.

### ۲.۴ صفحهٔ سیاه یا خرابی سیو

- مشکل مربوط به **AIO fix** است، نه خود BD-JB.
- از `Lapse.iso` نسخهٔ ۱.۲+ یا HENloader استفاده کنید (fix داخل ISO است).
- اگر از نسخهٔ قدیمی استفاده می‌کنید، `aiofix_network.elf` را بعد از HEN با BinLoader بفرستید.
- **همزمان چند fix یا پلاگین مختلف نصب نکنید.**
- اگر قبلاً fixهای متناقض نصب کرده‌اید، بهترین راه بازگرداندن بکاپ/نصب مجدد نیست؛ ابتدا پلاگین‌ها را حذف و تست کنید.

### ۲.۵ پیلود بارگذاری نمی‌شود

- USB را **قبل از** دیسک وصل کنید.
- فایل باید دقیقاً `payload.bin` و در روت باشد.
- فرمت FAT32 یا exFAT باشد.
- پیلود با فریمور سازگار باشد (GoldHEN/HEN مناسب).
- اگر ISO پیلود داخلی دارد، USB لازم نیست؛ README را بخوانید.
- در برخی نسخه‌ها پورت BinLoader روی ۹۰۲۰ است، نه ۹۰۹۰.

### ۲.۶ نوتیفیکیشن/منو دیده نمی‌شود

- `Settings → Notifications → Disable Pop-ups while playing video` را **خاموش** کنید.
- بعضی نسخه‌ها لاگ را فقط از شبکه می‌فرستند: `log_client.py` را روی پورت ۱۸۱۹۴ اجرا کنید.

### ۲.۷ پس از موفقیت، کنسول ناپایدار است

- پیلود/پلاگین ناسازگار را حذف کنید.
- از AIO fix و پیلود همراه همان ابزار استفاده کنید.
- کنسول را خاموش/روشن کنید و اکسپلویت را تازه اجرا کنید.
- اگر مشکل ادامه داشت، نسخهٔ ISO/پیلود را عوض کنید.

### ۲.۸ آپدیت خودکار فریمور

- آپدیت خودکار را غیرفعال کنید.
- در صورت امکان، DNS یا فایروال برای بلاک سرورهای آپدیت تنظیم کنید.
- اگر فریمور آپدیت شد و از بازهٔ پشتیبانی خارج شد، اکسپلویت قبلی کار نمی‌کند؛ راه‌حل فوری/عمومی وجود ندارد.

## ۳. جمع‌آوری لاگ برای عیب‌یابی

### ۳.۱ RemoteLogger (نسخه‌های Gezine)

1. روی PC، در پوشهٔ ریپو، `log_client.py` را اجرا کنید:

```bash
python3 log_client.py
```

2. سپس اپ BD-J را روی PS4 اجرا کنید.
3. لاگ‌ها روی پورت ۱۸۱۹۴ دریافت می‌شوند.

### ۳.۲ کنسول BinLoader

- با netcat به پورت ۹۰۲۰ وصل شوید و پیام‌ها را ببینید (در نسخه‌هایی که کنسول فعال دارند):

```bash
nc 192.168.1.50 9020
```

### ۳.۳ چه چیزی را گزارش کنیم؟

- مدل PS4 و فریمور دقیق.
- نام دقیق ISO/نسخهٔ ابزار.
- نوع دیسک (BD-R/BD-RE) و سرعت رایت.
- متن کامل خطا/لاگ.
- آیا USB وصل بود و نام فایل چه بود.

## ۴. چه زمانی متوقف شویم؟

اگر هر یک از این نشانه‌ها را دیدید، ادامه ندهید:

- کنسول بوت نمی‌شود یا صفحهٔ سیاه مداوم دارد.
- بوق/چراغ خطا (مخصوصاً چراغ آبی/سفید چشمک‌زن).
- پیام خرابی سیستم/داده.
- نیاز به نصب مجدد فریمور.

در این موارد:

1. برق را قطع کنید و چند دقیقه صبر کنید.
2. با Safe Mode (در صورت امکان) بوت کنید.
3. اگر دادهٔ مهم دارید، قبل از هر اقدام بازیابی، از آن بکاپ بگیرید (در صورت امکان).
4. از انجام دستکاری‌های بیشتر بدون راهنمای مشخص خودداری کنید.
