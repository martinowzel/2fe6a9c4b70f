# ۰۶ — سخت‌افزار و نرم‌افزار لازم

> این سند فهرست کامل چیزهایی است که برای مسیر دیسکی BD-JB (فریمور ۹.۰۰–۱۲.۵۲) لازم دارید، به‌همراه نکات خرید و تنظیمات.

---

## ۱. فهرست خرید سریع

| مورد | الزامی؟ | توضیح |
|---|---|---|
| PS4 با فریمور ۹.۰۰–۱۲.۵۲ | بله | فریمور دقیق را قبل از هر چیز بررسی کنید |
| رایتر بلوری (BD-RE/BD-R) | بله | داخلی SATA یا اکسترنال USB؛ باید دیسک بلوری **قابل رایت** پشتیبانی کند |
| دیسک BD-R یا BD-RE | بله | ۲۵ یا ۵۰ گیگابایت؛ **BDXL پشتیبانی نمی‌شود**؛ BD-RE برای تست/استفادهٔ مجدد بهتر است |
| USB فلش | بله (برای بار اول) | FAT32 یا exFAT؛ `payload.bin` در روت |
| کامپیوتر با نرم‌افزار رایت | بله | ImgBurn/PowerISO (ویندوز)، K3b (لینوکس)، BD-SimpleBurn (مک) |
| پیلود GoldHEN یا HEN | بله | نسخهٔ سازگار با فریمور؛ از منبع رسمی |
| شبکه/کابل اترنت (اختیاری) | خیر | برای RemoteJarLoader/لاگ/ارسال پیلود از PC |
| دیسک پیش‌رایت‌شده | جایگزین رایتر | فقط از فروشندهٔ قابل‌اعتماد؛ ریسک محتوا/کیفیت |

---

## ۲. رایتر بلوری

### ۲.۱ چه چیزی لازم است؟

- رایتری که بتواند **BD-R** و **BD-RE** رایت کند (نه فقط DVD/CD).
- اتصال داخلی SATA یا اکسترنال USB 2.0/3.0.
- پشتیبانی از سرعت‌های کم (۲x/۴x) برای پایداری بهتر.

### ۲.۲ نکات خرید

- رایترهای ارزان «فقط خواندن» (BD-ROM) به درد نمی‌خورند؛ حتماً **writer/burner** باشد.
- اگر رایتر اکسترنال می‌خرید، مطمئن شوید در سیستم‌عامل شما بدون درایور خاص شناسایی می‌شود.
- رایترهای قدیمی ممکن است BD-RE با ظرفیت بالا را پشتیبانی نکنند؛ به مشخصات دقیق نگاه کنید.

### ۲.۳ دیسک‌ها

| نوع | توضیح | توصیه |
|---|---|---|
| **BD-R** | یک‌بار رایت | برای دیسک نهایی/آرشیو |
| **BD-RE** | قابل پاک و رایت مجدد | برای تست و به‌روزرسانی ISO |
| **BDXL** | ظرفیت بالا (100GB+) | **پشتیبانی نمی‌شود**؛ استفاده نکنید |
| **DVD/CD** | — | برای BD-JB کار نمی‌کند |

- برندهای شناخته‌شده (Verbatim، Sony، Panasonic و مشابه) کیفیت پایدارتری دارند.
- دیسک‌های ارزان و بدون برند ممکن است در PS4 خوانده نشوند.
- برای BD-RE، در نرم‌افزار رایت گزینهٔ **permanent write / write once** را غیرفعال کنید تا دیسک قابل بازنویسی بماند.

---

## ۳. نرم‌افزار رایت

| سیستم‌عامل | نرم‌افزار | نکته |
|---|---|---|
| ویندوز | **ImgBurn** | ساده و شناخته‌شده؛ گزینهٔ «Write image file to disc» |
| ویندوز | **PowerISO** | جایگزین؛ در راهنمای ConsoleMods ذکر شده |
| لینوکس | **K3b** | در READMEهای BD-JB پیشنهاد شده |
| مک | **BD-SimpleBurn** | مخصوص مک؛ ریپو GitHub دارد |

### ۳.۱ اصول رایت

1. فایل ISO را **به‌صورت image** رایت کنید، نه کپی داده.
2. سرعت را پایین بگذارید (۲x/۴x)؛ برخی ابزارها گزینهٔ «verify» دارند، فعالش کنید.
3. برای BD-RE، حالت بازنویسی/پاک‌کردن را درست انتخاب کنید.
4. بعد از رایت، دیسک را در یک پخش‌کنندهٔ بلوری معمولی یا همان PS4 تست کنید.

> ISOهای BD-JB معمولاً کوچک‌اند (حدود ۱۶ مگابایت)؛ ظرفیت دیسک مهم نیست، اما **نوع دیسک و ساختار BDMV** مهم است.

---

## ۴. USB فلش و پیلود

- فرمت: **FAT32** یا **exFAT** (هر دو در READMEها پشتیبانی شده‌اند).
- فایل پیلود را در **ریشهٔ** USB قرار دهید و نام آن را دقیقاً `payload.bin` بگذارید.
- پیلود باید با فریمور شما سازگار باشد (GoldHEN/HEN مناسب).
- USB را **قبل از** دیسک وارد کنید.
- در بسیاری از نسخه‌ها، پس از اولین اجرا پیلود در `/data/payload.bin` کپی می‌شود و دیگر نیازی به USB نیست؛ اما این رفتار به ابزار بستگی دارد.

> هرگز `payload.bin` ناشناس را اجرا نکنید. پیلود مخرب می‌تواند به سیستم/داده آسیب بزند.

## ۵. تنظیمات PS4

| تنظیم | مقدار لازم | دلیل |
|---|---|---|
| **HDCP** | فعال | پخش بلوری/اجرای BD-J به آن نیاز دارد |
| **آپدیت خودکار** | غیرفعال | جلوگیری از آپدیت ناخواسته و از دست رفتن اکسپلویت |
| **اپدیت سیستم** | دستی/غیرفعال | همان دلیل |
| **BD-LIVE** | هنگام پرسش، YES | برخی نسخه‌ها برای اجرا به تأیید BD-LIVE نیاز دارند |
| **Disable Pop-ups while playing video** | خاموش (یعنی پاپ‌آپ‌ها مجاز) | برای دیدن نوتیفیکیشن‌ها/منوی اکسپلویت |
| **اتصال اینترنت** | فقط در صورت نیاز اولیه | اگر بلوری قبلاً فعال نشده، یک‌بار آنلاین شوید؛ بعد آفلاین |
| **اتصال PSN** | لازم نیست | برای BD-JB آفلاین نیازی نیست |

### ۵.۱ فعال‌سازی اولیهٔ پخش بلوری

اگر کنسول شما هرگز دیسک بلوری پخش نکرده است، ممکن است پخش‌کننده ابتدا نیاز به فعال‌سازی/اتصال اینترنت داشته باشد. در این حالت:

1. ابتدا **آپدیت خودکار** را غیرفعال کنید.
2. یک‌بار با اینترنت امن به شبکه وصل شوید و پخش بلوری را فعال کنید.
3. سپس می‌توانید آفلاین شوید.

### ۵.۲ خطای `NW-31201-7`

این خطا معمولاً به تنظیمات HDCP/شبکه/BD-LIVE مربوط است. مراحل پیشنهادی ConsoleMods:

1. `Settings → System → Automatic Downloads` را باز کنید و گزینه‌های «Allow Restart» و «System Software Update Files» را بردارید.
2. `Settings → Network → Set up Internet Connection` را دوباره با Easy setup تنظیم کنید.
3. `Settings → System → Enable HDCP` را فعال کنید.

## ۶. شبکه (اختیاری)

برای کارهای پیشرفته:

- **RemoteJarLoader:** ارسال JAR دلخواه به پورت ۹۰۲۵.
- **BinLoader/کنسول:** پورت ۹۰۲۰ (بسته به ابزار).
- **RemoteLogger:** پورت ۱۸۱۹۴ برای دیدن لاگ.
- ابزار ارسال: `netcat`/`ncat` یا اسکریپت‌های پایتون همراه ریپو (مثل `log_client.py`).

تنظیمات شبکه را فقط در شبکهٔ محلی قابل‌اعتماد انجام دهید؛ پورت‌ها را به اینترنت باز نکنید.

## ۷. چک‌لیست قبل از شروع

- [ ] فریمور دقیق PS4 را یادداشت کرده‌ام.
- [ ] سازگاری فریمور را در [جدول سازگاری](05-سازگاری-فریمور.md) بررسی کرده‌ام.
- [ ] رایتر بلوری و دیسک BD-R/BD-RE سالم دارم.
- [ ] ISO مناسب را از منبع رسمی/شناخته‌شده دانلود کرده‌ام.
- [ ] پیلود سازگار (GoldHEN/HEN) را از منبع رسمی گرفته‌ام.
- [ ] USB را FAT32/exFAT فرمت کرده و `payload.bin` را در روت گذاشته‌ام.
- [ ] HDCP را فعال و آپدیت خودکار را غیرفعال کرده‌ام.
- [ ] در صورت نیاز، پخش بلوری را فعال کرده‌ام.
- [ ] می‌دانم که بعد از جیل‌بریک نباید فریمور را آپدیت کنم.
